# currency-travel-bot

Telegram-бот «Миникошелёк для путешественника»: конвертирует валюты по курсу [exchangerate.host](https://exchangerate.host), ведёт бюджет поездки и показывает остаток сразу в двух валютах. Учебный кейс модуля 5 «Работа с API» курса «Профессия вайб-кодер 2.0» (урок VPd05, кейс 2).

## Что умеет

- `/start`: приветствие и главное меню кнопками.
- `/newtrip` или кнопка «Создать путешествие»: страна отправления, страна назначения, курс из API с вопросом «Подходит ли этот курс?». Если нет, курс вводится вручную (например, из местного обменника). Затем начальная сумма в домашней валюте, бот сам переводит её в валюту назначения через `/convert`.
- Любое число в чате = расход в валюте страны назначения. Бот показывает сумму в обеих валютах и спрашивает «Учесть как расход?».
- `/switch` или «Мои путешествия»: список поездок, переключение активной.
- `/balance` или «Баланс»: остаток в двух валютах, курс, начальная сумма.
- `/history` или «История расходов»: последние 10 трат.
- `/setrate` или «Изменить курс»: новый курс для текущей поездки.

Каждый пользователь видит только свои путешествия. Ошибки (не число, неизвестная страна, нет связи, неверный ключ, лимит запросов) обрабатываются понятными сообщениями. Страну можно написать по-разному («Италия», «италия», «Англия») или кодом валюты (`EUR`).

## Как устроено

| Файл | Что внутри |
|---|---|
| `current_api.py` | работа с API exchangerate.host: `get_current_rate` (/live), `convert_currency` (/convert), `get_pair_rate`, `get_all_supported_currencies` (/list) |
| `database.py` | SQLite (`travel_wallet.db`): пользователи, путешествия, расходы, справочник «страна → валюта» |
| `countries.py` | данные справочника стран и синонимы названий |
| `wallet.py` | логика диалогов и расчётов без Telegram, её проверяют тесты |
| `bot.py` | Telegram-бот на pyTelegramBotAPI, кнопки и команды |
| `tests/test_bot.py` | 24 теста на моках, без сети и Telegram |

Если бесплатный тариф API не даёт `/convert`, курс пары считается через `/live` (кросс-курс через USD).

## Запуск

1. Получить бесплатный ключ на exchangerate.host и токен бота у @BotFather.
2. Установить зависимости:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Скопировать `.env.example` в `.env` и вписать свои значения `CURRENCY_ACCESS_KEY` и `TELEGRAM_TOKEN`.
4. Проверить ключи и связь с API: `python bot.py --check`
5. Запустить бота: `python bot.py`

Дополнительно:

- `python bot.py --console`: диалог с логикой бота прямо в терминале, без Telegram.
- `python current_api.py`: быстрая проверка модуля API.
- `python -m pytest -q`: тесты.
